# Mariem Baatout — AI Engineer Portfolio

Portfolio React/Vite bilingue (français / anglais), avec identité sombre violet-cyan, animations, cartes de projets interactives, compétences, parcours, langues et téléchargement du CV PDF.

## Démarrer en local

Prérequis : Node.js 18+ et npm.

```bash
npm install
npm run dev
```

Pour construire et tester la version de production :

```bash
npm run build
npm run preview
```

## Personnalisation importante

- `src/main.jsx` : textes, projets, compétences, expériences, langues et liens.
- `src/style.css` : thème, responsive, animations et styles.
- `public/CV-Mariem-Baatout.pdf` : le PDF téléchargé par le bouton « Télécharger mon CV ».
- Le bouton GitHub est ajouté, mais pointe actuellement vers `https://github.com/` car l'URL exacte de ton profil GitHub n'était pas fournie. Remplace cette URL dans `src/main.jsx` par le lien de ton profil.

## Publication

Déploiement possible sur Vercel, Netlify ou GitHub Pages.
